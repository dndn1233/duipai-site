# 对拍 Groove 产品介绍页

这是一个独立、无外部依赖的响应式 H5 产品介绍页，可用于：

- 甲方/老师项目汇报
- 小程序推广落地页
- 社团招新/项目路演展示
- 后续放置体验二维码

## 使用

直接打开 `index.html` 即可预览。

## 文案主线

1. 一句话定位：让想一起玩音乐的人更快找到彼此
2. 痛点：找人难、成团后组织分散、社团运营重复劳动
3. 核心能力：对拍、音乐主页、聊天、乐队、活动公告、排练设备
4. 用户路径：建档 → 匹配 → 沟通 → 成团 → 持续活动
5. 双边价值：乐手体验 + 社团运营

## 上线前建议替换

- CTA 区域的体验二维码
- 如有真实真机截图，可替换目前的演示摄影素材或增加“产品实拍”章节
- 如推广范围不限成都工业学院，可保持目前的通用“校园音乐人”定位
