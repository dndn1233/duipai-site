Why Groove

校园里不缺喜欢音乐的人，缺的是让他们真正连接起来的方式。

群聊擅长通知，却不擅长匹配；朋友圈能展示作品，却很难回答“谁正好缺一个贝斯手”。对拍 Groove 把这些原本分散的动作重新组织成一条清晰路径。

01 / MATCH

找人靠碰运气

乐器、风格、空闲时间和组队意愿散落在聊天记录里，很难快速判断是否合适。

02 / ORGANIZE

成团之后又很分散

成员、作品、招募、排练和沟通分别存在不同地方，乐队缺少持续经营的数字空间。

03 / OPERATE

社团运营重复劳动

活动报名、公告、排练室和设备借用都需要单独统计，信息也很容易被聊天消息淹没。

Core Features

核心不是“功能多”，而是每一步都接得上。

从第一次看到一个合适的乐手，到建立联系、加入乐队、参与活动和持续排练，核心能力围绕真实音乐社交关系组织。

对拍 · 找乐手 / 找乐队

通过职位、曲风、资料与匹配信息快速认识同频的人，也可以直接查看正在招募的乐队。

先看是否合拍，再决定要不要聊

个人音乐主页

用封面、乐器职位、音乐简介、照片、视频、音频和演出履历，让“我会什么”比一句自我介绍更有说服力。

让作品替你完成第一轮自我介绍

私聊与群聊

支持私聊、乐队群和活动群，并承接资料查看、语音沟通、入队邀请与请求，让匹配不只停留在卡片上。

从认识到约一次排练

乐队主页与组织

展示成员、招募缺位、乐队作品与演出信息；队长可以围绕自己的乐队处理成员和后续协作。

一支乐队有自己的长期空间

活动与公告

活动报名、详情、名单与活动群聊集中处理；公告支持文字、图片与视频，让重要社团信息不再完全依赖群消息。

让参与活动这件事更明确

排练与设备协同

围绕真实社团资源管理排练时段和设备借用，让队长能够在同一平台完成从组队到排练的后续动作。

社交最终落到真实音乐活动
User Journey

一个乐手真正会走的路径。

产品价值不在某一个页面，而在于用户不需要离开系统，就能完成从“我想找人”到“我们真的开始一起玩”的全过程。

01

建立音乐身份

完善乐器、曲风、个人资料与作品，让别人能快速判断你的方向。

02

对拍发现同频乐手 / 招募乐队

不是只看头像，而是结合音乐信息、当前状态和完整主页做决定。

03

私聊、听作品、确认想法

从“看起来合适”进入真实沟通，再决定是否进一步组队。

04

加入或创建乐队

成员关系、招募信息和乐队主页进入稳定组织状态，而不是继续散落在群聊里。

05

活动、排练、作品持续沉淀

乐队不只是“建了一个群”，而是逐渐留下成员、内容和真实活动记录。

Product Value

既服务乐手，也让社团运营真正更轻。

对学生，它是音乐社交和组队工具；对社团管理者，它把成员关系、活动和公共资源逐步沉淀为可管理的体系。
